# Цифровая трансформация операционной деятельности предприятия

Курсовая работа на примере ООО «Сервис» — небольшого онлайн-сервиса цифровых
подписок (B2C), который продаёт доступ к облачному сервису по подписке на 1, 3
и 12 месяцев.

## Тема, цель и задачи

**Тема.** Цифровая трансформация операционной деятельности предприятия.

**Цель работы** — разработать и обосновать модель цифровой трансформации
операционной деятельности малого онлайн-сервиса: перейти от ручных операций
(приём заявок, сверка платежей, выдача доступа, поддержка, выкладка версий) к
автоматизированным процессам с измеримым эффектом.

**Задачи:**

1. Раскрыть понятие цифровой трансформации операционной деятельности и выбрать
   методологию анализа (модели зрелости, процессный подход).
2. Проанализировать процессы предприятия «как есть», выявить узкие места и
   оценить долю ручного труда.
3. Спроектировать целевую модель процессов «как будет».
4. Описать архитектуру ИТ-решения, его данные, интеграции и меры безопасности.
5. Составить план внедрения с управлением изменениями и откатами.
6. Оценить эффективность: KPI «до/после» и модельный экономический расчёт с
   анализом чувствительности.
7. Выявить риски и предложить меры по их снижению.
8. Подтвердить работоспособность ключевого автоматизированного процесса
   демонстрационной программой с автоматическими тестами.

**Объект исследования** — операционная деятельность ООО «Сервис».

**Предмет исследования** — процессы продажи, оплаты, выдачи доступа,
поддержки клиентов и эксплуатации ИТ-системы, а также методы и средства их
цифровой трансформации.

**Методы:** процессный анализ (нотация «как есть / как будет», схемы потоков),
оценка цифровой зрелости, хронометраж и экспертная оценка трудозатрат,
сравнительный анализ показателей до и после, модельный экономический расчёт,
анализ чувствительности, прототипирование.

> Предприятие обезличено. Данные, которых нет в открытом виде (объёмы заказов,
> ставки, затраты), приведены как **оценочные (модельные)**, с расчётом в тексте,
> чтобы любой вывод можно было проверить и пересчитать.

## Как запустить демо

Нужен только Python 3.9 или новее.

```bash
# тесты (30 штук, около 5 секунд)
python3 -I -m unittest discover -s demo/tests -t .

# сервис
export DEMO_WEBHOOK_SECRET=change-me
python3 -m demo.app
curl -s localhost:8000/health
```

Подробности и пример полного сеанса «заказ → оплата → токен» — в
[`demo/README.md`](demo/README.md).
